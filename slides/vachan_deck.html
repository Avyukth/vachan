VACHANTHE THESIS
CODE-GATED
One architectural decision

Code — not the model — decides when private data and write-tools unlock.

LAYER 1
Context isolation
Account data enters the LLM only at CONFIRMED — the model cannot leak what it was never given.
LAYER 2
Tool isolation
read_account / commit_promise throw unless CONFIRMED. Every denial is a ledger row.
LAYER 3
Fixed templates before verification
The LLM selects the reply; it never writes it.
LAYER 4
Output guard before every utterance
Multilingual blocklist. On fire: discard the draft, speak a safe line, log OUTPUT_BLOCKED.
